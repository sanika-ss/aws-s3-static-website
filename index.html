Welcome to My AWS Project

This website demonstrates static website hosting using Amazon Simple Storage Service (Amazon S3).

Explore Project

Project Objective

To host a static website on Amazon S3 and understand cloud storage, website hosting, and public access settings.

AWS Services Used

  • Amazon S3
  • AWS Management Console

Implementation Steps

  • Create an S3 bucket.
  • Upload the index.html file.
  • Enable static website hosting.
  • Configure the required permissions.
  • Open the website using its S3 website endpoint.

Project Outcome

This project demonstrates the basic process of deploying a static website using AWS S3.
