# AWS S3 Static Website Hosting

## Project Overview
This project demonstrates how to host a static website using Amazon S3.

## Objective
To deploy a static website on AWS S3 and make it accessible through a website endpoint.

## AWS Services Used
- Amazon S3
- AWS Management Console

## Implementation Steps
1. Created an S3 bucket.
2. Uploaded website files, including index.html.
3. Enabled static website hosting.
4. Configured the required bucket permissions.
5. Accessed the website using the S3 website endpoint.

## Outcome
Successfully practiced hosting a static website using Amazon S3.

## Skills Learned
- Cloud Storage
- S3 Bucket Configuration
- Static Website Hosting
- Basic AWS Permissions

## Future Scope
The website can be improved by using Amazon CloudFront, HTTPS, and a custom domain.
